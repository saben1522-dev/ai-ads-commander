# AI Ads Commander Free v0.2

Static edition for free public hosting. No Node.js, billing, or API key is required.

## Publish with GitHub Pages

1. Create a GitHub repository, e.g. `ai-ads-commander`.
2. Upload `index.html` and this README.
3. GitHub → Settings → Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select `main` and `/ (root)` → Save.
6. Wait for deployment. GitHub gives a public URL like `https://USERNAME.github.io/ai-ads-commander/`.

This edition runs its baseline audit engine in the browser and stores the latest audit in browser localStorage. It does not access private Seller Centre data and does not execute campaigns.

## Free custom domain

In GitHub Pages Settings → Custom domain, enter your domain/subdomain and follow the DNS records GitHub shows. Do not guess DNS values.

## Important

The free edition is intentionally local/static. Gemini API, private platform data, database, authentication, and automated campaign execution require a backend and authorized platform integrations later.
